# Carpeta de Imágenes

Esta carpeta contiene las imágenes utilizadas en el portfolio.

## Instrucciones para agregar imágenes:

1. Coloca tus imágenes en esta carpeta `public/images/`
2. Las imágenes se referencian en los componentes como `/images/nombre-imagen.jpg`

### Imágenes actuales:

- **dashboard-powerbi.jpg** - Dashboard de Power BI de VisualNacert (maquinaria, personal, suministros)

### Formatos recomendados:

- JPG/JPEG para fotografías
- PNG para imágenes con transparencia
- WebP para mejor compresión (recomendado para web)
- SVG para logos e iconos

### Tamaño recomendado:

- Máximo 2MB por imagen
- Resolución recomendada: 1920x1080 o menor
- Comprime las imágenes antes de subirlas para mejor rendimiento
