📸 Guía: Cómo Agregar Imágenes a tu Portfolio

Paso 1: Guarda tu imagen del Dashboard

Para el dashboard de Power BI que compartiste:

  1. Abre la imagen del dashboard en tu navegador o visor de imágenes
  2. Haz clic derecho > Guardar imagen como...
  3. Guárdala en: PRB-Portfolio/public/images/
  4. Nómbrala como: dashboard-powerbi.jpg

Paso 2: La imagen ya está configurada

✅ ¡Buenas noticias! Ya configuré el dashboard en tu experiencia de VisualNacert. Solo necesitas guardar la imagen con el nombre correcto en la carpeta public/images/

Paso 3: Agregar más imágenes (opcional)

Para agregar imágenes a otros hitos, edita el archivo src/components/Experience.vue:

Ejemplo: 
{
  id: 2,
  title: 'Integración de Stripe',
  description: 'Sistema de pagos...',
  technologies: ['Stripe', 'Django'],
  images: ['stripe-dashboard.jpg', 'payment-flow.png']
}

🎯 Ubicación de las imágenes

Ruta completa:

C:\Users\live4life\Desktop\PRB-Portfolio\public\images\

Imágenes que necesitas agregar:

  • ✅ dashboard-powerbi.jpg - Dashboard de VisualNacert (ya configurado)
  • Cualquier otra imagen que quieras mostrar en tus hitos

📋 Formatos recomendados

  • JPG/JPEG: Para fotografías y capturas de pantalla
  • PNG: Para imágenes con transparencia
  • WebP: Para mejor compresión (más moderno)

Tamaño máximo recomendado: 2MB por imagen

Resolución: 1920x1080 o menor

🚀 ¡Listo!

Una vez guardes las imágenes en la carpeta, el servidor de desarrollo las detectará automáticamente. Solo recarga tu navegador en http://localhost:5173 para verlas.
